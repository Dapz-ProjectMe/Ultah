# Birthday Valonika — Premium

Struktur:
- `index.html` — halaman utama
- `css/style.css` — seluruh styling
- `js/script.js` — seluruh interaksi/animasi
- `assets/music.mp3` — tempat menaruh file musik yang kamu punya hak untuk digunakan

Catatan musik:
Website mencoba autoplay, tetapi browser dapat memblokir autoplay audio bersuara.
Fallback-nya adalah memulai musik ketika pengguna menekan tombol pembuka.
Jangan upload lagu berhak cipta kecuali kamu memiliki hak/izin untuk menggunakannya.

Deploy ke Vercel:
1. Upload folder project ini ke GitHub.
2. Import repository di Vercel.
3. Framework Preset: Other / None.
4. Build Command: kosong.
5. Output Directory: `.`.
6. Deploy.
